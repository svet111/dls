# dls
## 1. game_of_thrones
В этом домашнем задании вам нужно будет решить задачу классификации, а именно задачу предсказания выживет ли персонаж из Игры Престолов или нет. Ноутбук с домашним заданием открыт только в режиме просмотра. Для выполнения задания необходимо скопировать ноутбук на свой Google Drive или выполнять ноутбуки локально в программе Jupyter Notebook.

Есть две части этого домашнего задания: 

Решить задачу классификации и отправить предсказания лучшей модели на Stepik. Результат вашей лучшей модели будет оцениваться на тестовой выборке по метрике Accuracy. За прохождение определенных порогов будут начисляться баллы. Критерии оценивания можно найти в ноутбуке. Этот пункт оценивается до 5 баллов. Для этого мы предварительно разделили данные в задании на две части.
game_of_thrones_train.csv. На этом наборе данных вам необходимо создать и обучить модель. Подробное описание файла есть в ноутбуке.
game_of_thrones_test.csv. Предсказания для этого набора необходимо записать в файл submission.csv и сдать в соответствующий шаг на Stepik. Количество попыток ограничено 100 штук.
На протяжении решения ноутбука, вам будут попадаться задания, которые необходимо будет решить. За каждую выполненную часть будет начислено определенное количество баллов. В этом пункте вам необходимо отправить файл в формате .ipynb на Stepik --- для этого в домашнем задании есть отдельный шаг. Этот пункт оценивается до 5 баллов.

## 2. hw_kaggle
В этом домашнем задании вам нужно будет решить задачу машинного обучения, оформить ноутбук и отправить результат предсказания на проверку в тестирующую систему. Подробные инструкции по выполнению задания есть в ноутбуке hw_kaggle.ipynb.

Есть две части этого домашнего задания: 

Отправить ваши предсказания в  Stepik. За прохождение определенных порогов будут начисляться баллы. Эта часть оценивается из 5 баллов. Для этого мы предварительно разделили данные в задании на две части.
train.csv. На этом наборе данных вам необходимо создать и обучить модель. Подробное описание файла есть в ноутбуке.
test.csv. В каждой строчке файла data_scoring.csv указаны признаки тестовых объектов. Предсказания для этого набора необходимо записать в файл submission.csv и сдать в соответствующий шаг на Stepik. Количество попыток ограничено 100 штук.
Сделать полноценный отчет о вашей работе: как вы обработали данные, какие модели попробовали и какие результаты получились. За каждую выполненную часть будет начислено определенное количество баллов. В этом пункте вам необходимо отправить файл в формате .ipynb на Stepik --- для этого в домашнем задании есть отдельный шаг. Этот пункт оценивается из 10 баллов.
